# SahaKarya 

> Empowering rural and informal gig workers through a Democratic Cooperative Marketplace backed by Fair-Share Matchmaking and Social Security.

---

##  Key Highlights
* **Fair Job Allocation (ML):** Dynamically allocates daily tasks equally across active workers to prevent lead monopolization.
* **Voice AI Booking:** Integrates Bhashini API to parse spoken regional dialects, removing digital literacy barriers.
* **Taluka Level Hyperlocal Focus:** Uses PostgreSQL + PostGIS geofencing to keep jobs, workers, and capital circulating locally.
* **Doorstep Trust & Verification:** Multi layer security featuring DigiLocker e-KYC, digital police clearance, and customer photo-ID matching.
* **Dual OTP Flow:** Start and Finish OTP handshakes guarantee verified task commencement and completion.
* **Instant Emergency Response:** One tap 112 SOS panic trigger with real time location streaming to family contacts and emergency responders.
* **Equitable Payout Split:** 90% direct payout to the worker via Setu UPI, with a built in 2% ring fenced health and pension reserve.
